# Nuxt + Tailwind 迁移回归清单

> 适用阶段：Phase 0 及后续每个 PR  
> 执行方式：手工回归（必要时补自动化）

## 1. 执行说明

- 每次迁移 PR 至少覆盖“核心路径”。
- 若改动涉及某模块，必须补跑该模块完整用例。
- 验收记录建议写在 PR 描述：`用例编号 + 结果 + 截图`。

## 2. 环境基线

- 后端：`http://localhost:3000`
- 前端（旧）：`http://localhost:5173`
- 前端（Nuxt 迁移中）：按阶段配置（见进度文档）
- 测试账号：
  - 普通用户：可访问所有业务页，不可访问管理页
  - 管理员用户：可访问管理页

## 3. 核心路径（每次必测）

### AUTH（登录/鉴权）

- [ ] AUTH-01 用户名密码登录成功并跳转到记事页
- [ ] AUTH-02 未登录访问受保护页面时跳转登录页
- [ ] AUTH-03 已登录访问登录页时跳转回默认页
- [ ] AUTH-04 token 失效后触发 401 并回到登录页
- [ ] AUTH-05 退出登录后本地会话清理完成
- [ ] AUTH-06 二步验证流程（如开启）可完整通过

### NOTES（记事）

- [ ] NOTES-01 记事列表加载成功（含分页）
- [ ] NOTES-02 搜索、筛选（全部/置顶/归档）行为正确
- [ ] NOTES-03 新建记事成功并出现在列表
- [ ] NOTES-04 编辑记事成功并能刷新回显
- [ ] NOTES-05 删除记事成功并从列表移除
- [ ] NOTES-06 置顶/取消置顶状态正确

### PLANS（计划）

- [ ] PLANS-01 计划列表加载正常
- [ ] PLANS-02 创建计划成功
- [ ] PLANS-03 计划步骤新增/编辑/删除成功
- [ ] PLANS-04 步骤排序更新成功
- [ ] PLANS-05 分享链接查看与 PIN 校验流程正常

### EXPENSE（记账）

- [ ] EXP-01 记账列表加载正常（年月筛选有效）
- [ ] EXP-02 新增/编辑/删除记录成功
- [ ] EXP-03 分类新增/删除正常
- [ ] EXP-04 统计图与统计数字正常展示

### NOTIFICATION（通知）

- [ ] NOTI-01 通知列表加载成功（分页）
- [ ] NOTI-02 单条已读、批量已读、全部已读生效
- [ ] NOTI-03 未读角标与汇总数字同步更新

### SHARE（公开分享）

- [ ] SHARE-01 访问有效分享链接展示正确
- [ ] SHARE-02 PIN 错误时提示正确
- [ ] SHARE-03 PIN 正确后可查看计划及步骤
- [ ] SHARE-04 分享过期/次数耗尽时提示正确

## 4. 样式与交互（Tailwind 共存期必测）

- [ ] UI-01 主题切换正常（pink/mint/lavender/peach/sky）
- [ ] UI-02 按钮主样式、危险样式、禁用态无回归
- [ ] UI-03 输入框 focus/error 态无回归
- [ ] UI-04 移动端底部导航布局正常
- [ ] UI-05 桌面端侧边栏折叠与导航高亮正常
- [ ] UI-06 常见弹窗（新建/删除确认/提示）样式正常

## 5. PWA（相关任务阶段必测）

- [ ] PWA-01 可安装（manifest 正常）
- [ ] PWA-02 离线打开已访问页面可用
- [ ] PWA-03 新版本更新提示与刷新策略正常
- [ ] PWA-04 Push 订阅、取消订阅流程正常

## 6. 兼容性抽查

- [ ] COMP-01 Chrome（桌面）
- [ ] COMP-02 Edge（桌面）
- [ ] COMP-03 移动端浏览器（至少 1 种）
